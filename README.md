# AssessIQ – AI-Powered Real-Time Assessment Platform

## Project Overview
AssessIQ is a web-based assessment platform that allows teachers to create quizzes and students to take assessments and view their scores.

## Technologies Used
- Java
- Spring Boot
- HTML, CSS, JavaScript
- MySQL
- Maven
- Git and GitHub

## Main Features
- User registration and login
- Student quiz interface
- Teacher assessment management
- Automatic answer evaluation and score calculation
- Assessment attempt storage
- Student results dashboard

## How to Run Locally
1. Install Java and MySQL.
2. Create a MySQL database named `assessiq`.
3. Configure your local database credentials in `backend/src/main/resources/application-local.properties`.
4. Open a terminal in the `backend` folder.
5. Run `.\mvnw.cmd spring-boot:run`.
6. Open `http://localhost:8080` in your browser.
